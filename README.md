Deccan Spice & Grill 🌶️🔥

Artisanal Indian Fine-Casual Dining Web Application

Where Royal Deccan Spices Meet Live Charcoal Embers.

🌐 Live Demo: https://roshikosuru-dot.github.io/Deccan-Spice-and-Grill/

📖 Overview

Deccan Spice & Grill is a responsive, single-page restaurant website crafted for an authentic Indian fine-casual dining experience with flagship outlets in Hyderabad (Banjara Hills) and Vijayawada (MG Road). Built with zero build-step complexity using semantic HTML5, Tailwind CSS, and Vanilla JavaScript, the site delivers a seamless browsing, ordering, and table-booking experience across mobile, tablet, and desktop devices.

✨ Key Features

Editorial Hero & Brand Showcase: Warm charcoal, saffron, and terracotta visual theme accented with custom geometric Deccan mandala and copper handi SVG artwork.

Interactive Menu with Real-Time Filtering (₹ INR):

Filter dishes across Starters, Main Course, Biryani & Breads, and Desserts & Beverages.

Pure Veg Only toggle switch alongside standard FSSAI Veg/Non-Veg indicators and spice-level badges (Mild, Medium, Spicy, Fiery).

Instant keyword search bar across dish names and descriptions.

Slide-Over Dining Tray & Bill Estimator:

Add, increment, or remove dishes directly from menu cards or the hero showcase.

Real-time subtotal, promo discount, 5% GST, and grand total calculation in Indian Rupees (₹).

Curated Special Offers & One-Click Promo Codes:

Interactive offer cards with instant clipboard copy for promo codes (THALI349, FEAST550, DECCAN20).

Dynamic Guest Reviews:

Displays verified customer reviews with an interactive star-rating form that appends new reviews live to the page.

Multi-Branch Location & Instant Table Reservations:

Switchable location details, hours, interactive vector map, clickable phone links, and a direct WhatsApp concierge button for both Hyderabad and Vijayawada.

Both an inline reservation form and a quick-access modal with instant booking reference generation.

🛠️ Tech Stack

Markup: Semantic HTML5

Styling: Tailwind CSS (via CDN with custom saffron, terracotta, charcoal, and sand palette)

Typography & Icons: Google Fonts (Playfair Display & Inter) + Font Awesome 6 + Custom Inline SVGs

Interactivity: Vanilla JavaScript (ES6+)

🚀 Getting Started

Because this project is self-contained in a single index.html file with no external build tools required, you can run or deploy it immediately:

Clone the repository:

git clone https://github.com/roshikosuru-dot/Deccan-Spice-and-Grill.git


Open locally:
Navigate to the project folder and open index.html directly in any modern web browser (or use the VS Code Live Server extension).

Deploy via GitHub Pages:
Push changes to the main branch and ensure GitHub Pages is configured to serve from the root directory (/).
